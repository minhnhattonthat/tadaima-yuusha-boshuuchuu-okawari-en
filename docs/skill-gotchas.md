# Skill gotchas

One line per gotcha: the reference file it belongs in, then the fact.

- scripts/lua/mesen_lib.lua: `L.on_read` on a ROM range ($80/$C0 mirrors) logged nothing here while the code plainly read it; `L.on_read` on WRAM works. Follow the copy in RAM, or log callers with an exec hook (`tools/debug/calllog.lua`). Cause not found.
- references/platform-snes.md: a game can have a run-the-rest-in-VBlank call (`$80D78F` here: queues its return address, or returns at once in forced blank). Look for it before writing an upload path: name tiles took one record and one DMA call.

- references/setup.md: `fetch_emu.py` fails with CERTIFICATE_VERIFY_FAILED when Python's CA store is stale; `gh release download` works instead, and `python -c "import certifi"` alone doesn't fix urllib.
- scripts/emu.py: `ppudump.lua` needs `--frames` or `DUMP_AT`; a `--route`-only run stops with a Lua error before any frame.
- references/emulator-qa.md: Mesen `watch.lua` reports WRAM writes as `00FCA000` for `$7E:A000` (the probe's address field isn't the CPU address on this path); trust the PC, not `addr`.
- references/platform-snes.md: `dis65816.py` loses M/X across branches; restart at each target with the right `--m8/--x8` when a routine mixes widths.
- scripts/emu.py: `--mash 90` left the opening stuck on one dialogue box while 4-frame presses every 150 frames advanced it; a route or `L.press` works, cause not found.
- references/emulator-qa.md: cold boots here drift by a few frames between runs (state 16 at f483 or f485, warp at f3502 or f3532), so a route counted in frames from boot lands wrong; count from a RAM state instead.
- references/emulator-qa.md: a `--script` file can't `dofile` a repo-relative path, Mesen's cwd isn't the repo; `warp.lua` derives the root from `OUT`.
- scripts/lua/probes/watch.lua: it logs each PC once, so a decompressor rewriting a watched buffer later looks like no write at all; compare a RAM dump with the expected bytes before ruling an overwrite out.
- references/emulator-qa.md: a menu on a dice or board game can sit in a handler that never returns to the dispatcher, so poking the state byte does nothing; write it from an exec hook on the dispatcher. Text that looks like a corrupt font can be a warp into a state the data tables don't define for that value: dump the per-chapter tables before debugging the text path.
- references/pipeline.md (Identity): byte-identical LZ recompression can need never-read look-ahead words copied from the dump (the original tool left stale buffer there), and gaps between blocks can hold data: check before blanking them.
- references/pipeline.md (Identity): before settling for a decompress-equal test, compare the original's tokens with plain greedy longest-nearest: all 749 blocks here matched, one script's work, and `bytes.rfind` compresses 2.7 MB in 4 s in pure Python.
- hooks/guard_bash.py: it blocks a whole chained command if any part pipes tests, even when commit comes after `&&` on a later line; run `check.py` in its own call.
- scripts/lua/mesen_lib.lua: `L.safe` drops return values, so an `L.on_write` callback can't override the written value; patch at the reader instead (`warp.lua` hooks the dispatcher).
- references/pipeline.md (Extract): a clean-kana string filter misses strings glued to data with no terminator (name lists, records ending in a name), and a scan that skips "already covered" ranges hid a whole text range here; audit the data pieces for kana runs too, and scan without the mask.
- references/pipeline.md (Extract): before tracing every pointer to raw strings, consider a control code at each string's start that jumps to new text: list walks and computed tables then need no tracing (proposed here, not yet proven).
- hooks/guard_bash.py: a heredoc writing a .py file is blocked, while `python - <<'X'` on stdin passes; throwaway analysis still works that way.
references/platform-snes.md: on a cooperative scheduler a wait routine that takes a number may be sleep-until-signal, not a frame count ($80E11C here: id 6 = input poll, 2 = never): read the signal side before changing it. A prompt loop that samples input must stay in step with the poll: a slower draw in its loop plus a frame-locked mash (period 30, loop 10) missed every press.
- references/graphics.md (Survey): labels can be `W H tiles` records in tile numbers of a small sheet, not any glyph encoding: relative search in findtext-style tools misses them. Dump the BG map, search the tile run, then log the blit (`LDA #ptr / STA src`, JSL). A brute scan of code banks for W H + tiles in the kana range found every record, unseen screens included.
- references/platform-snes.md: a task on a cooperative scheduler can't spin on a queue another task drains: sleep a frame instead. A `clear`-style helper that sets Y is easy to miss in a hook where the caller's Y is the text pointer.
- scripts/hooks/guard_bash.py: `sed -i` is blocked even as a no-op on /dev/null, and a chained command with `| tail` hides a build failure from a later `&&`: write the build output to a file and grep for success.
- references/pipeline.md (Marker) / emulator-qa.md: "free" RAM from unchanged dumps (ramuse) is not free: a buffer tail that the game fills with the same bytes each time looks unchanged. Prove it with a write watch on the ORIGINAL over the whole scene tour (lowmap.lua + freeram.py here); our upload records sat in the sprite buffer and caused random crashes and black screens that varied run to run.
- references/platform-snes.md: a VBlank continuation queue (game routine that pops its caller and runs the rest later) keeps the list node in the record itself: records must be in bank 0 and nothing else may write them; each game caller owns a static record. Cooperative task schedulers give each task its own stack in $1Fxx: unwritten bytes there are stack slack, not free RAM.
- scripts/emu.py Lua (Mesen): L.on_write callback addresses for writes through another bank (DB=$82 writing $0480) came back as e.g. 0xFC0480 / 0x1020480, not 0x7E0480: mask with & 0x1FFF for low RAM before comparing.
- references/platform-snes.md (asar): asar 1.91 evaluates math left to right (no precedence unless `math pri on`): `!A+!B*8` is `(A+B)*8`. A ring bound written that way never wrapped and walked through low RAM. Bracket every mixed expression or put `math pri on` at the top of the patch.
- references/pipeline.md (Marker, width gate): with a VWF that keeps the game's cell cursor, a page/wait arrow drawn at the cursor lands ON the last partially filled cell (it was never advanced past): "(end)" showed "(en▼". Test the width gate with a short line ending mid-cell before {page}, not only full lines; and a full last line pushes the arrow onto a new line (window scrolls), so lines before a prompt need one cell less.
- references/platform-snes.md (VWF/tile hooks): if a hook SLEEPS (task yield) inside a routine the game never yields in, other tasks clobber the shared direct-page scratch ($00-$1F) the caller keeps loop counters in. Symptom here: a list drew rows past its end, overflowed an unchecked 11-entry blit list, and a 0-row entry spun 64 KB DMAs (black screen). Save/restore DP around every sleep in hook code.
- references/emulator-qa.md (debug tool): lastpc.lua showing a single PC then nothing for a frame can be a huge DMA (CPU stalled on $420B), not an STP; log the DMA size/count variables before assuming a crash.
- references/pipeline.md (Marker): a per-line far-code encoder that drops empty lines changes the box height the game blits; the old line stays on screen. Keep the source's line count.
- references/translation.md (batches.py ADAPTER): rows shorter than a far code (here < 3 bytes) must fit English in place; the check must measure bytes for them, or the build asserts late. Glyphs the JP font has (star, button icons, heart) belong in FREE as raw bytes, or agents swap in ASCII.
- references/translation.md §Review: with codex out of credits and nested workers refused, a fresh write-capable agent per batch (not its translator) that writes the report and a `--dry`-checked fix file, merged by the controller one at a time, kept the controller's context small (~40k tokens per agent, one-line replies).
- assets/batches.py: a review needs a `fix FILE` command (id<TAB>English rows, check then overwrite); `merge` only takes whole batches.
- references/translation.md §Review: correction to the line above. A reviewer that must also write every Important fix, with a Minor cap, files voice/register findings as Minor to save work (~70 here, caught by the phase review). Keep review read-only (`reviewer` type), no cap, fix as a separate step.
- references/pipeline.md §Checks: romdiff allowed ranges for asar hooks can come from the asm itself: assemble onto an all-00 and an all-FF blank image and take every byte either run changed (tools/romcheck.py). asar `--fix-checksum=off` leaves the header checksum stale: fix it in the build (bps.snes_checksum).
- assets/batches.py: the stub-last-line check needs exceptions for a speaker-label line above, a `{sub}` on the line and capitalised exclamations, or most hits are false; lowercase-start under 6 chars caught the 13 real ones.
- references/translation.md (reflow): a paragraph reflow tool must skip list rows, not only choices and menus: this game's 12-record place lists (one name per {nl}, a far call per record) were classed as dialogue and reflowed to 4 lines, so 8 records showed blank in the map-town box. batches.form now has a `list` form whose lint checks the record count.
- references/emulator-qa.md §Debug tool: a save-menu warp straight from party creation shows the slot list and the confirm prompt but never writes the save (はい chosen too): scenes that need a real save (save slot dates) need another route.
- references/graphics.md: graphics text on SNES can sit in an LZ block that a build already re-packs (block 002 buttons, 794 title menu here): decode the block, redraw the cells in Python at build time (tools/gfx.py) and let the repack fit it; both streams still fit their slots.
- references/emulator-qa.md §Hooks (Mesen): emu.setState inside an exec callback changes registers (A, Y, DBR took effect) but not PC: the opcode at the hooked address is already fetched and still runs, so a "loop back" by setting cpu.pc does nothing.
- references/emulator-qa.md §emu.py: --var values are globals shared by every --script: pclog.lua's FROM overwrote sweep.lua's FROM in one run. Give a probe's vars distinct names.
- references/emulator-qa.md §Text coverage: RE probes left in the tour command (6 Lua scripts with per-char and RAM write hooks) made each scene 7x slower (93 s vs 13 s per 3000 frames); keep them opt-in (regen.py --probes). The textcover read hooks cost ~1.5x.
